# Plataforma-de-Control-y-Certificaci-n-de-Ausencias-Cl-nicas-USS
Demo del sistema de justificación de inasistencias para estudiantes de Odontología USS. Permitirá registrar solicitudes asociadas a cursos y actividades clínicas, adjuntar respaldos, validar plazos y notificar a docentes y administradores. Se integrará al Portafolio Digital de Odontología.
